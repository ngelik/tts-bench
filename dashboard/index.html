Metric definitions and comparability

Generation

Warm, full-article timing uses the selected language fixture after one excluded warm-up. Warm v2 uses three scored articles, except eligible single-observation models that retain one; legacy v1 results keep their original five-round or eligible single-round count. Every count is available in model details. WebGPU can include CPU work. Exact versions and protocols are available in each receipt. Read the benchmark text ↗

RAM

Mean sampled Chrome process RSS comes from a separate cached full-article run. It includes the browser and workers, is not GPU VRAM, and does not represent a minimum hardware requirement.

Weights

Verified core model files in decimal MB, including vocoder where applicable. Runtime, voices, text processing and transfer overhead are excluded.

Evidence

Open a model for full receipts, versions, settings, support and license details. Audio samples help judge speech quality; they do not rank timing.
