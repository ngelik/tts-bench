# Notices

This project is a Chinese-language adaptation of `tiny-voca` by Muhammed Nazeem.

- Upstream project: <https://github.com/n4ze3m/tiny-voca>
- Upstream license: Apache-2.0

The teacher model used during data generation was `Qwen3-TTS-12Hz-1.7B`, obtained through ModelScope and released under Apache-2.0. The Chinese front-end, training data preparation, evaluation pipeline, and final Chinese model were created for this project.
