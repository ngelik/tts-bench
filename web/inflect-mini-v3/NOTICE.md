# Inflect Mini v3 browser-port notices

The Mini checkpoint and its pinned source are from `owensong/Inflect-Mini-v3`
at Hugging Face revision `fdefa06ed090ba0f3e1c5e455c492d2a0b9512e6`. The model
card declares Apache-2.0. This port converts its FP32 Cassidy inference path
to three dynamic ONNX graphs and a length-indexed style table; the checkpoint
is not redistributed in this repository.

The conversion and ONNX output are generated by
[`tools/export-inflect-mini-v3.py`](../../tools/export-inflect-mini-v3.py),
using the pinned source file and dependency manifests in
[`tools/inflect-mini-v3-conversion.lock.json`](../../tools/inflect-mini-v3-conversion.lock.json).
The graph/source implementation is an Apache-2.0 adaptation of the pinned
Mini inference source. The adjacent `LICENSE` retains the Apache-2.0 terms.

The runtime frontend is a separate browser configuration. It uses the shared
Inflect Micro v3 numeric normalization and source-preserving splitter plus the
Klein 0.2.0 contextual English G2P adaptation and pinned local browser eSpeak
fallback. It does not claim parity with native Mini's Misaki 0.9.4 + bundled
eSpeak frontend. The fixed Cassidy style table is selected from the Mini
checkpoint. Noise is seeded with browser Mulberry32 + Box-Muller rather than
PyTorch's generator. The CPU harmonic source and STFT are a Float32 browser
port; native waveform comparison remains a separate, strict diagnostic.

ONNX Runtime Web is MIT with its third-party notices. Klein G2P and lexicon
retain their Apache-2.0 attribution. Browser eSpeak NG retains GPL-3.0-or-later
terms. The asset lock stages the required runtime licenses and notices for the
selected configuration. The repository's root MIT license does not relicense
these components.
