# Browser Voice Hindi INT6 notice

This profile selects Tamal Hansda's Hindi Voice Compact INT6 checkpoint and the fixed Ishwari voice. It uses native Hindi script from `hi-article-v1`; the Roman-input converter is not used. The checkpoint revision is `04e39413827f3d45af54ceb480cb77e732983c1b`; the browser worker source is pinned separately at `f2977727b8baccb989f80b492ea8da00124ecba3`. Asset URLs, byte lengths and SHA-256 digests, including both G2P graphs and the immutable credits file, are in `assets.lock.json`.

Tamal Hansda’s Hindi INT6 checkpoint is Apache-2.0. The 20-hour Ishwari training dataset uses CC BY 4.0 for its synthetic recordings and original annotations. Its Hindi prompts credit the Mozilla Common Voice Sentence Collector (CC0) and AI4Bharat Rasa contributors via the indic-tts-mini-24k transcript index (CC BY 4.0). [Pinned dataset card](https://huggingface.co/datasets/Hansda/hindi-maya2-ishwari-20h/blob/c835a1a2c3892f5cd47507824bf33df19deec955/README.md)

The pinned publisher credits identify Tiny Voca by Muhammed Nazeem under Apache-2.0, Maya 2 Native, Kyutai Mimi (CC BY 4.0), eSpeak NG pronunciation labels, and Dakshina lexicons for Roman-input converters. This profile takes native Hindi input and does not use the Roman converter. ONNX Runtime Web 1.24.3 is MIT. The relevant Apache and MIT license texts are retained or referenced in the asset lock.

At UI speed 1 the stock browser uses `paceScale` 0.9719864176570459. The worker uses one-thread WASM for acoustic and G2P inference. The reported 934,704 scalar values count the 200 external acoustic graph initializers; they exclude the separate G2P encoder and decoder. No speech-quality or benchmark claim is made by this source profile.
