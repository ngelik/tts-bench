# Klein-TTS browser port source and changes

The model source is the public [Klein-TTS X1.5 Pro ONNX checkpoint](https://huggingface.co/klein-ml/Klein-TTS-X1.5-Pro/tree/25e0e73bebba71e5985bc369628ebdcb81bf7116/onnx), pinned at revision `25e0e73bebba71e5985bc369628ebdcb81bf7116`. Its model card declares Apache-2.0. The benchmark downloads the two ONNX graphs and `model.json` to the ignored asset cache; weights are not in Git. `LICENSE-model` retains the Apache-2.0 license served from that pinned HF revision and is hash-checked into the local assets cache.

There is no verified official browser runtime for this checkpoint. The upstream [NPM package `@kleinml/kleintts@0.2.0`](https://www.npmjs.com/package/@kleinml/kleintts/v/0.2.0) is explicitly a Node.js CPU package (`onnxruntime-node` and `espeak-ng`). Its source is available from the [versioned NPM tarball](https://registry.npmjs.org/@kleinml/kleintts/-/kleintts-0.2.0.tgz), SHA-512 integrity `sha512-qb91ypyHgR0YKOYqdCN0AuDlS75J+LSXrlAuszAoi1puM87fXXsouLL3j/R1gloxThMt4MyOivNse1J5KUg7lA==`. Source attribution and the original package notice are in `NOTICE-upstream`; its Apache-2.0 license is in `LICENSE-upstream`.

`g2p.mjs` is modified from the upstream package's `src/g2p.js`. The benchmark replaces Node file access and the native eSpeak dependency with a same-origin fetch of the pinned lexicon and the repository's pinned browser `phonemizer.js`. Browser eSpeak omits optional tie marks, so explicit no-tie forms for English diphthongs and affricates are normalized to the model's phoneme alphabet. The English dictionary is the upstream NPM package's `data/en_us_lexicon.json.gz`, staged from the versioned package URL with its exact byte count and SHA-256 in `assets.lock.json`.

`model.mjs` adapts the upstream `src/model.js` and text chunker/noise generator in `src/index.js`. The worker runs the upstream exported ONNX graph contract through ONNX Runtime Web 1.23.2; the benchmark-specific worker, ORT integration, audio collection and adapter bridge are original integration code. Upstream sentence-first 250-character grouping is retained. Unknown symbols fail explicitly. Where a source span exceeds the 510-token graph limit, the benchmark re-phonemizes and splits at source word boundaries to retain all text rather than using upstream's silent unknown-symbol skips and token truncation. The canonical span ID determines the deterministic noise seed. These are disclosed frontend/runtime differences from the Node package.

The browser `phonemizer.js` package is Apache-2.0 and includes eSpeak NG data/code under GPL-3.0-or-later. ONNX Runtime Web is MIT and its third-party notices are staged with the runtime. The package's `NOTICE` attributes the Misaki English lexicon and lookup rules; `LICENSE-misaki` retains the Apache-2.0 text provided with the pinned HF checkpoint. The root MIT license does not relicense these components.
