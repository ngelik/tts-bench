# Apptor Tiny TTS, Standard German

This profile uses the Standard German checkpoint from [apptor/apptor-tiny-tts](https://huggingface.co/apptor/apptor-tiny-tts/tree/0b6962273a1d6618f250cdbd621b56ba04b62cef) at revision `0b6962273a1d6618f250cdbd621b56ba04b62cef`. The TTS weights and G2P code/weights are Apache-2.0. The optional Vocos ONNX second stage is MIT. See the staged model and Vocos license texts and the source model card.

The browser G2P, tokenization, German number normalization, and Vocos-kernel implementation are adapted from the author's browser source at [apptor/apptor-tiny-tts-at revision `e28eb444250b4d06162e6ba8e5090c4284345913`](https://huggingface.co/apptor/apptor-tiny-tts-at/tree/e28eb444250b4d06162e6ba8e5090c4284345913/web). The pinned G2P graph, G2P metadata, and Vocos graph have the same SHA-256 digests in the Standard German repository; the browser phone-symbol inventory matches the Standard German TTS config in order. Browser exception readings were compared with the Standard German Python exceptions and English-word map. Austrian exception data and pronunciation rules are not shipped. Austrian model weights and the `accent` graph input are never loaded.

The harness fixes the Standard German `M2` voice, speed `1.0`, pitch shift `0`, pitch range `1.0`, Vocos enabled, 24 kHz output, and the author's 120 ms gap between sentence/clause segments inside each fixed fixture chunk. The fixture's 109 required source spans can split sentences, so an extra pause is not inserted between separate source chunks; that is an integration boundary difference from a single whole-article `speak()` call. It retains the upstream -30 dB tail threshold and 40 ms cosine fade, then caps peaks at 0.95. The Standard German graph has no accent input. Long spans use the author's non-quick-start sentence then clause segmentation; empty, dropped, or over-limit speakable input fails visibly.

ONNX Runtime Web 1.23.2 uses its MIT license and bundled third-party notices. The backend reports `cpu/wasm` or `webgpu+wasm`; WebGPU is reported as qualified only after an actual compute-dispatch probe.
