# Sopro v2 Turbo

Sopro by Samuel Vitorino is licensed under [Apache-2.0](LICENSE.txt). The benchmark uses the official desktop streaming implementation at [7bfcf9a](https://github.com/samuel-vitorino/sopro/tree/7bfcf9a0539d274f6593959a21da948f506ceee1/web). The local entry derives from upstream `web/src/index.js`. Its three static imports and two ONNX Runtime imports point to hash-pinned local files, and the immutable manifest permits cache reads offline. The DSP, tokenizer and cache modules are the original source bytes. ONNX Runtime Web 1.31.1 falls within upstream’s dependency range. Both profiles request four threads in isolated desktop Chrome.

The official ONNX conversion includes two native profiles. CPU uses wasm-uint8. GPU uses webgpu-fp16, with reference and autoregressive semantic inference on WASM and acoustic and vocoder inference on hardware WebGPU. The complete exported graphs plus weights are 338.59 MB for CPU, 363.32 MB for GPU, or 509.82 MB for both profiles staged together after deduplicating shared files. Runtime and prompt bytes are additional. Profile sizes describe the export, and actual resource loads are measured separately where available. Precision differs, so the two results are independent observations. [Pinned export manifest](https://huggingface.co/samuel-vitorino/sopro-v2-turbo-onnx/blob/9fe97bddf52ed785af3634db86a032bb7e07bf18/manifest.json)

The reference is the benchmark’s 30-second synthetic F2 clip from [Tiny Voca’s scored CPU trial](../../results/2026-11-16t17-55-16-727z-tiny-voca-cpu-warm-be739c20/summary.md). Tiny Voca is by Muhammed Nazeem. The bounded voice input permits reproduction without obtaining a recording of a human speaker. The fixture is the original English article. The worker decodes the existing 24 kHz mono PCM16 directly, and upstream crops on a pause around ten seconds, normalizes the reference and extracts conditioning features during initialization. No caller audio is uploaded. English, seed 1 per source span, two acoustic steps, default temperature and sampling settings are fixed. The worker rejects tokenizer truncation. A semantic loop exhausting its 30-second output budget raises an explicit span error. Completed spans therefore ended before the cap. The worker emits the first nonempty CPU-readable streaming block. Each measured article still produces one complete waveform.

All scored trials include per-span sample counts and the benchmark’s post-timer PCM16 constant-run check. The counts permit inspection of unusually short spans and alignment of the final WAV with the source text.
